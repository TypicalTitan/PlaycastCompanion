# Optional brand art (not shipped)

This folder is **gitignored** on purpose. The app renders an original drawn mark
on every lighting card, so nothing needs to be here.

If you personally hold artwork you are licensed to use (e.g. from a vendor's
official press kit, under its terms), you may drop PNGs here and they will be
embedded into *your* local build and shown in place of the drawn marks:

| File | Shown on |
|---|---|
| `razer.png` | Razer card (square mark, ~56 px) |
| `steelseries.png` | SteelSeries card |
| `logitechg.png` | Logitech G card |
| `corsair.png` | Corsair card |
| `openrgb.png` | OpenRGB card |
| `windows.png` | Windows Dynamic Lighting card |

Also `Assets/squid.png` (one level up) replaces the generated app icon.

Do not commit any of these to a public fork unless you have the right to
redistribute them.
